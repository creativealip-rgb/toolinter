# Toolinter — Keyword Gap & Content Strategy

_Disusun: 2026-07-14. Basis: audit blog + riset kompetitor (Mekari Talenta, KlikGaji, simulasikredit, iLovePDF, SmallPDF)._

## Prinsip

1. **JANGAN lawan keyword "head" finansial.** "kalkulator gaji", "kalkulator pph21", "hitung gaji bersih" sudah dikuasai Mekari Talenta + KlikGaji + simulasikredit yang pakai kalkulator sebagai umpan SaaS (budget SEO besar). Domain baru = kalah head-on.
2. **JANGAN pivot ke market luar.** Keunggulan Toolinter 100% keindonesiaan (surat format ID, PPh21/BPJS/PTKP, CV ATS Indonesia, UMR per kota). Ke global = buang moat, langsung kalah lawan iLovePDF/SmallPDF/Canva (DA 90+).
3. **MENANG di long-tail transaksional** yang raksasa HRIS malas garap + intent jelas. Ini kekuatan asli Toolinter (22 tool surat + 7 tool CV).
4. **RPM tinggi tetap dari dalam ID** — keyword finansial (KPR, invoice, modal, pesangon) RPM di atas rata-rata Indonesia. Pertajam, jangan tinggalkan.

## Aksi konten

- **Fokus 111 artikel unik** (hasil dedup) — jadikan pillar, jangan clone lagi.
- **Setiap artikel WAJIB tautkan ke tool relevan** (CTA sudah ada di skema `ctaHref`) — ini yang bedain dari kompetitor content-only.
- **Internal linking** antar artikel se-kategori untuk topical authority.
- **Publish bertahap tapi ORGANIK** — jangan "7/hari tanggal berurutan" (pola doorway). Sebar natural.
- **Update tahunan** angka pajak/UMR/PTKP (E-E-A-T signal: konten di-maintain).
